Initial Android release of Undertow.

See the README for supported features, browser sign-in instructions, and build requirements. The verification record lists tested behavior and device limitations.

TIDAL integration is unofficial. Browser sign-in is needed for the lossless access verified during development; device-code access may return AAC. Protected streams are unsupported.

Install the APK from this release. Its SHA-256 checksum is listed in SHA256SUMS. Android 8 or later is required. Google Play Services are not required.
